# LinuxYandexMusicDRPC

> Missing Discord RPC for Yandex Music — now available for Linux.

A clean and modern Discord Rich Presence client that shows what you’re listening to on Yandex Music — directly from your Linux system using MPRIS.

---

## Features
- Native Linux support (via D-Bus / MPRIS)
- Discord Rich Presence with album covers
- Works with browsers and native players
- Auto-fetches album info from Yandex API

---

## Install
```bash
git clone https://github.com/AkaruiNekoOFF/LinuxYandexMusicDRPC.git
cd LinuxYandexMusicDRPC
pip install -r requirements.txt
python3 main.py
````
